Consejos de Preparación

🌡️ Temperatura

La temperatura ideal del agua está entre 90-96°C para extraer los mejores sabores.

⏱️ Tiempo

El tiempo de extracción varía según el método: 2-4 minutos para filtro, 25-30 segundos para espresso.

💧 Proporción

Recomendamos una proporción de 1:15 a 1:17 (café:agua) para métodos de filtro.

🔄 Frescura

Muele el café justo antes de prepararlo para obtener el máximo sabor y aroma.
